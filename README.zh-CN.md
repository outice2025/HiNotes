简单易用的 100% FOSS Android 笔记应用，使用 Jetpack Compose 与 Material 3 Expressive 构建。

笔记与应用设置均保存在本地；应用不申请 INTERNET 权限。

### 功能

**笔记**
- 新建、编辑、删除笔记。
- 首页按标题与正文搜索笔记。
- 首页按最近修改、创建时间、标题排序笔记。
- 首页单、双列列表排序笔记。
- 首页长按笔记可批量操作。
- 笔记支持以 Markdown 格式书写。
- 笔记导入、显示图片。
- 笔记可导出为`.md`或`.txt`。
- 锁定、置顶笔记。

**微件**
- 桌面微件支持显示独立的笔记。
- 可选择是否显示笔记标题。
- 可单独设置微件的字号与字重。
- 支持渲染 Markdown 格式的笔记。
- 配色跟随应用配色方案。

**编辑器**
- 支持以 Markdown 格式编辑、预览笔记。
- 支持笔记内查找。
- 支持快捷工具栏。
- 支持自动保存。
- 支持显示笔记信息。

**外观**
- Material You 配色方案/动态取色。
- 支持 AMOLED 深色模式。
- 支持字号、字重调节。

**备份**
- 支持导出/导入设置、笔记。
- 支持恢复默认设置。
- 支持导出诊断报告。

**隐私**
- 无统计、无追踪、无账号。
- 支持应用内屏幕保护。
- 支持密码解锁应用。
- 笔记与设置保存在本地。
- 应用不发起任何网络请求。

**语言**
- 英文、简体中文。
