A simple, easy-to-use, 100% FOSS Android notes app built with Jetpack Compose and Material 3 Expressive.

Notes and app settings are stored locally; the app does not request the INTERNET permission.

### Features

**Notes**

- Create, edit, and delete notes.
- Search notes by title and body on the Home screen.
- Sort notes by last modified, creation time, or title on the Home screen.
- Display notes in single- or two-column lists on the Home screen.
- Long-press notes on the Home screen for batch operations.
- Write notes in Markdown.
- Import and display images in notes.
- Export notes as .md or .txt.
- Lock and pin notes.

**Widgets**

- Home screen widgets can display individual notes.
- Optionally show note titles.
- Set widget font size and weight independently.
- Render Markdown-formatted notes.
- Colors follow the app's color scheme.

**Editor**

- Edit and preview notes in Markdown.
- Find within notes.
- Quick toolbar.
- Auto-save.
- Display note information.

**Appearance**

- Material You color schemes / dynamic color.
- AMOLED dark mode.
- Adjustable font size and weight.

**Backup**

- Export/import settings and notes.
- Restore default settings.
- Export diagnostic reports.

**Privacy**

- No analytics, no tracking, no accounts.
- In-app screen protection.
- Unlock the app with a password.
- Notes and settings are stored locally.
- The app makes no network requests.

**Languages**

- English, Simplified Chinese.
